# ManvirSDh.github.io

Personal site, served by GitHub Pages at https://manvirsdh.github.io

Plain static HTML/CSS — no build step. Edit `index.html`, push to `main`, Pages redeploys.

- `index.html` — the page
- `style.css` — styles (dark by default, light via `prefers-color-scheme`)
- `resume.pdf` — the résumé the page links to
- `.nojekyll` — disables Jekyll processing (keeps `_`-prefixed files)

Local preview: `python3 -m http.server 8000` then open http://localhost:8000
